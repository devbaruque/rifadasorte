Entrar

Este painel só grava com um token do GitHub com acesso ao repositório do site. Sem ele, nada pode ser alterado. O token fica apenas neste navegador.

Como criar o token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Expiration: 60 dias. Repository access: Only select repositories → escolha o repositório da rifa.
  3. Permissions → Repository permissions → Contents: Read and write. Nada mais.
  4. Copie o token e cole aqui. Ao final da rifa, apague o token no GitHub.
